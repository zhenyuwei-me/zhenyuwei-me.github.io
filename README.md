# Zhenyu Wei — Academic Homepage

Personal academic website for Zhenyu Wei, a Ph.D. student at ShanghaiTech University working on humanoid robotics and embodied AI.

**Website:** https://zhenyuwei-me.github.io/

## Editing and preview

The site uses plain HTML, CSS and JavaScript. No build step is required. Edit `index.html`, `publications.html` and files in `assets/`.

```sh
python3 -m http.server 8777 --bind 127.0.0.1
```

GitHub Pages serves the `main` branch from the repository root. All local URLs are relative to support the project path.

The site includes light and dark themes and an on-demand, three-image DexHLM carousel.
